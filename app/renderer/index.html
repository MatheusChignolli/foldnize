Foldnize

Tidy up folders by their media's original date.

1. Pick a folder

Choose any folder on your computer. Foldnize will scan it recursively for .heic, .jpeg, .jpg, .mov, .mp3, .mp4, and .png files.

No folder selected

2. Choose options

Mode

Enter a name. Files will become name-YYYYMMDD-HHMMSS.ext

Defaults: .heic, .jpeg, .jpg, .mov, .mp3, .mp4, and .png. Custom values are comma-separated and may include the leading dot.

File limit

Only the selected number of supported files are counted and processed. Choose 1–1000; the default is 50 and the same limit applies to Dry run.
